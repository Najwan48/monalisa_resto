## 1. Pendahuluan

### 1.1 Tujuan Dokumen

Dokumen ini disusun sebagai panduan bagi pengunjung (guest) dalam menggunakan fitur-fitur yang tersedia pada Website Company Profile Restaurant Monalisa Bogor. Panduan ini menjelaskan cara navigasi, menjelajahi menu, melihat galeri, menghubungi restoran, dan fitur-fitur lainnya.

### 1.2 Tentang Restaurant Monalisa Bogor

Restaurant Monalisa adalah restoran kuliner tradisional Indonesia yang berlokasi di Jl. Raya Tajur No. 30, Kota Bogor. Didirikan sejak tahun 1998, restoran ini menyajikan hidangan otentik nusantara dengan resep warisan turun-temurun selama lebih dari 25 tahun.

### 1.3 Prasyarat Akses

| Komponen | Kebutuhan |
|----------|-----------|
| Perangkat | Desktop, laptop, tablet, atau smartphone |
| Browser | Google Chrome, Mozilla Firefox, Microsoft Edge, Safari (versi terbaru) |
| Koneksi Internet | Diperlukan untuk mengakses website |
| Autentikasi | Tidak diperlukan (akses publik) |

## 3. Halaman Katalog Menu

Halaman katalog (`katalog.php`) menampilkan daftar lengkap menu restoran dengan fitur pencarian dan filter.

### 3.1 Pencarian Menu

| Elemen | Deskripsi |
|--------|-----------|
| Kolom search | Input teks untuk mencari menu berdasarkan nama |
| Tombol search | Ikon kaca pembesar untuk memulai pencarian |
| Tombol "Hapus" | Menghapus kata kunci pencarian |

**Cara menggunakan:**
1. Ketik nama menu yang ingin dicari pada kolom pencarian.
2. Tekan **Enter** atau klik ikon **kaca pembesar** untuk memulai pencarian.
3. Hasil pencarian akan menampilkan menu yang sesuai.
4. Klik tombol **"Hapus"** untuk menghapus kata kunci dan kembali ke daftar lengkap.

### 3.2 Filter Kategori

Filter kategori tersedia dalam dua tampilan:

**Desktop (tablet dan desktop):**
- Tombol-tombol kategori horizontal: Semua, Sup & Soto, Nasi & Utama, Camilan, Minuman, Lainnya.
- Tombol panah kiri/kanan untuk scroll jika kategori tidak muat.

**Mobile (smartphone):**
- Dropdown select untuk memilih kategori.

**Cara menggunakan:**
1. Klik tombol kategori yang diinginkan (contoh: "Sup & Soto").
2. Daftar menu akan difilter sesuai kategori.
3. Klik **"Semua"** untuk menampilkan semua menu kembali.

### 3.3 Daftar Menu

Setiap menu ditampilkan dalam bentuk kartu yang berisi:

| Elemen | Deskripsi |
|--------|-----------|
| Foto menu | Gambar hidangan dalam format WebP |
| Badge kategori | Label kategori di atas foto |
| Nama menu | Nama hidangan |
| Deskripsi singkat | Keterangan singkat tentang menu |
| Harga | Harga dalam Rupiah |
| Link "Detail" | Mengarahkan ke halaman detail menu |

**Cara menggunakan:**
- Klik pada kartu menu atau link **"Detail"** untuk melihat informasi lengkap menu.

### 3.4 Paginasi

Jika jumlah menu melebihi 12 item, navigasi paginasi akan tampil di bagian bawah.

| Elemen | Deskripsi |
|--------|-----------|
| Tombol halaman | Nomor halaman (1, 2, 3, ...) |
| Tombol aktif | Halaman yang sedang ditampilkan (warna berbeda) |
| Tombol nonaktif | Halaman lain yang dapat diklik |

**Cara menggunakan:**
- Klik nomor halaman untuk berpindah ke halaman tersebut.
- Halaman aktif ditandai dengan warna yang berbeda.

## 4. Halaman Detail Menu

Halaman detail (`detail.php?id=N`) menampilkan informasi lengkap satu menu hidangan.

### 4.1 Informasi Menu

| Elemen | Deskripsi |
|--------|-----------|
| Foto menu | Gambar hidangan berukuran besar |
| Kategori | Jenis menu (contoh: "SUP & SOTO") |
| Nama menu | Nama hidangan lengkap |
| Asal daerah | Daerah asal masakan (contoh: "Kudus, Jawa Tengah") |
| Harga | Harga dalam Rupiah |
| Deskripsi | Penjelasan detail tentang hidangan |

### 4.2 Bahan dan Alergen

| Elemen | Deskripsi |
|--------|-----------|
| Komposisi Utama | Daftar bahan-bahan utama hidangan |
| Informasi Alergen | Peringatan alergen jika ada (warna merah) |

**Catatan:** Jika menu tidak memiliki informasi alergen, bagian ini tidak akan ditampilkan.

### 4.3 Pemesanan

Terdapat 4 opsi pemesanan yang tersedia:

| Opsi | Fungsi |
|------|--------|
| Tombol GoFood | Membuka halaman GoFood di tab baru |
| Tombol GrabFood | Membuka halaman GrabFood di tab baru |
| Tombol WhatsApp | Membuka chat WhatsApp dengan pesan otomatis berisi nama menu dan harga |
| Tombol Telepon | Melakukan panggilan telepon langsung ke restoran |

**Cara menggunakan:**
- Klik **GoFood** atau **GrabFood** untuk memesan melalui platform online.
- Klik **WhatsApp** untuk mengirim pesan langsung ke restoran. Pesan otomatis akan berisi nama menu dan harga.
- Klik **Telepon** untuk langsung menelepon restoran.

**Tombol "Kembali ke Katalog Menu":**
- Tautan di bagian atas halaman untuk kembali ke daftar menu.

**Menu tidak ditemukan:**
- Jika menu dengan ID tertentu tidak ada atau nonaktif, halaman menampilkan pesan "Menu tidak ditemukan" dengan tombol "Kembali ke Katalog".

## 6. Halaman Kontak dan Lokasi

Halaman kontak (`kontak.php`) menampilkan informasi kontak restoran dan peta lokasi.

### 6.1 Informasi Kontak

| Elemen | Deskripsi | Interaksi |
|--------|-----------|-----------|
| Alamat | Jl. Raya Tajur No. 30, Kota Bogor | Klik untuk membuka Google Maps |
| Jam Operasional | Setiap Hari: 08.00 - 21.00 WIB | Informasi statis |
| Telepon | Nomor telepon restoran | Klik untuk menelepon + tombol salin |
| WhatsApp | Link ke WhatsApp | Klik untuk membuka chat WhatsApp |

**Cara menggunakan:**
- **Alamat:** Klik alamat untuk membuka lokasi di Google Maps.
- **Telepon:** Klik nomor telepon untuk langsung menelepon. Klik ikon **copy** di sebelah nomor untuk menyalin ke clipboard. Teks "Tersalin" akan muncul sebagai konfirmasi.
- **WhatsApp:** Klik **"Hubungi via WhatsApp"** untuk membuka chat WhatsApp langsung.

### 6.2 Peta Lokasi

Peta interaktif yang menunjukkan lokasi restoran:

| Elemen | Deskripsi |
|--------|-----------|
| Peta | OpenStreetMap interaktif |
| Marker | Pin lokasi restoran |
| Popup | Nama restoran dan petunjuk arah |

**Cara menggunakan:**
- **Zoom in/out:** Gunakan tombol +/- di peta atau scroll mouse.
- **Geser peta:** Klik dan drag pada area peta.
- **Petunjuk arah:** Klik pada **marker (pin)** untuk membuka Google Maps dengan petunjuk arah.
- **Klik popup:** Klik pada popup marker untuk langsung diarahkan ke Google Maps.

### 6.3 Warisan Monalisa

Bagian bawah halaman menampilkan filosofi "Monalisa Art" sebagai identitas visual restoran, dilengkapi gambar karya seni.

## 8. Widget WhatsApp

Widget WhatsApp adalah fitur floating chat yang tersedia di semua halaman publik.

### 8.1 Tombol Floating

| Elemen | Deskripsi |
|--------|-----------|
| Posisi | Pojok kanan bawah layar |
| Ikon | Logo WhatsApp (hijau) |
| Visibility | Tampil di semua halaman |

**Cara menggunakan:**
- Klik tombol **WhatsApp** di pojok kanan bawah untuk membuka popup chat.

### 8.2 Popup Chat

Popup yang muncul saat tombol WhatsApp diklik:

| Elemen | Deskripsi |
|--------|-----------|
| Header | Judul "Chat dengan Kami" |
| Input pesan | Kolom teks untuk menulis pesan custom |
| Tombol "Kirim" | Mengirim pesan ke WhatsApp |
| Tombol "X" | Menutup popup |

**Cara menggunakan:**
1. Klik tombol WhatsApp di pojok kanan bawah.
2. Ketik pesan pada kolom input.
3. Klik tombol **"Kirim"** untuk langsung diarahkan ke WhatsApp dengan pesan yang sudah diketik.

### 8.3 Tombol Cepat (Quick Reply)

Tiga tombol pesan cepat yang tersedia di popup:

| Tombol | Fungsi |
|--------|--------|
| Detail Menu | Mengirim pesan "Saya ingin bertanya tentang menu" |
| Pesan Menu | Mengirim pesan "Saya ingin memesan" |
| Lokasi | Mengirim pesan "Saya ingin bertanya lokasi restoran" |

**Cara menggunakan:**
- Klik salah satu tombol cepat untuk langsung mengirim pesan template ke WhatsApp.
- Pesan akan otomatis terisi sesuai tombol yang dipilih.

## 9. Navigasi Website

### 9.1 Menu Navigasi Utama

Menu navigasi utama tampil di bagian atas setiap halaman:

| Menu | Halaman Tujuan |
|------|---------------|
| Logo/Merek | Halaman Beranda (index.php) |
| Beranda | Halaman Beranda (index.php) |
| Menu | Halaman Katalog Menu (katalog.php) |
| Galeri | Halaman Galeri (galeri.php) |
| Kontak & Lokasi | Halaman Kontak (kontak.php) |
| Tentang | Halaman Tentang Kami (tentang.php) |

**Cara menggunakan:**
- Klik pada menu navigasi untuk berpindah halaman.
- Halaman yang sedang aktif akan ditandai dengan highlight/warna berbeda.

### 9.2 Footer

Footer tampil di bagian bawah setiap halaman dan berisi:

| Elemen | Deskripsi |
|--------|-----------|
| Copyright | Informasi hak cipta dengan tahun berjalan |
| Info kontak | Alamat dan nomor telepon restoran |

### 9.3 Responsivitas

Website dirancang responsif dan dapat diakses dengan baik di berbagai perangkat:

| Perangkat | Tampilan |
|-----------|----------|
| Desktop (>1024px) | Layout multi-kolom penuh |
| Tablet (768-1024px) | Layout menyesuaikan layar |
| Mobile (<768px) | Layout single-kolom dengan menu hamburger |

**Menu Hamburger (Mobile):**
- Di perangkat mobile, menu navigasi digantikan dengan ikon **hamburger** (tiga garis horizontal).
- Klik ikon hamburger untuk membuka menu navigasi.
- Klik di luar menu atau klik ikon **X** untuk menutup menu.
